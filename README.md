# MCNR-Net: A Tri-Domain CT Reconstruction Network With Learnable Measurement Error Correction and Nested Refinement

This repository contains sparse-view CT and limited-angle reconstruction pytorch codes for the following paper：  
Xiaohong Fan, Jiahao Yan, Yujie Feng, Xiaoqin Xia, Jianping Zhang and Shousheng Luo, “MCNR-Net: A Tri-Domain CT Reconstruction Network With Learnable Measurement Error Correction and Nested Refinement”, under review.
